# Experiment 3 — отчёт о реализации и проверках

Дата: **2026-11-02**, Asia/Almaty. Серверы, приложение, Docker, браузер и графический интерфейс не запускались. Внешние HTTP-проверки не выполнялись.

## Реализовано

Три независимых исследования в фиксированном протоколе: 45 сценариев исходных уровней, 45 сценариев весов, 255 leave-one-edge-out сценариев G1. Все 345 сценариев включают 182 перехода, всего 62 790 оценок. Расчёты вызывают существующий `run_experiment` и прежнее математическое ядро; альтернативные записи существуют только в памяти.

Новый kind ExperimentRun `experiment3` сохраняет полный envelope, scenario/baseline IDs, конфигурации, hashes и provenance. Старые запуски не обновляются. Добавлены раздел интерфейса, heatmap, кривые, таблицы M2/M3, ранжирование рёбер по четырём критериям и CSV/JSON/SVG/PNG.

### Backend

- Все сценарии/популяции/контроли, уникальные ID, корректные baseline references и независимость A/B/C.
- A0 и B0 точно совпадают с существующим движком; B1 совпадает с явно выбранным альтернативным источником.
- A0/A1/A2 воспроизводятся отдельными повторными расчётами stress-сценария G3; кэшированный replay полного envelope даёт равный payload. Известный уровень 0 и explicit null различаются; target-записи не подменяются.
- B2 имеет полное покрытие единичными весами и нулевой fallback; исходные недостающие веса B0 остаются явно отмеченными. Диагностика всех 7 ролей × 3 источника, normalization=none.
- Все 51 LOO-конфигурации содержат ровно 50 рёбер, сохраняют вершины и ацикличность; хеши и excluded/included IDs проверены.
- Для C M2 неизменна, M3 не возрастает. Во всех сценариях M3≥M2 при выбранных положительных λ.
- Знаковые/абсолютные разницы, совпадающие ранги, Spearman, Kendall τ-b, null для постоянных рангов, Top-K и рейтинги рёбер.
- CSV содержит 345 / 62 790 / 9 660 / 255 строк данных; JSON полностью восстанавливает envelope. Для каждого source/model в rankings CSV — 13 target ranks.
- Загруженный реальный Experiment 2 после расчёта Experiment 3 побитово совпадает по сериализованному JSON. Исходные ORM requirements/weights и CSV остаются неизменны. Существующие регрессии покрывают прежние исследования.

### Frontend

- Загрузка сохранённого Experiment 3, только pinned version в запросе, пять имён экспорта.
- Разделение A/B/C; 15 строк A/B для выбранного графа, 255 строк C и рейтинг 51 ребра; G1 фиксирован для C.
- Переключение критериев влияния, отсутствие вымышленных нулей при неопределённом Spearman.
- SVG с длинными подписями и provenance без XML parsererror, пустая heatmap с сообщением.
- Регрессии Experiment 2, старых результатов, графов, версий и экспорта проходят. Общие тесты PNG проверяют iTXt/pHYs и CRC; Canvas настоящего браузера не выполняется.

## Известные ограничения

- Веб-приложение и реальная PostgreSQL/pgvector в этой итерации не проверялись. Визуальная проверка браузера, реальная загрузка SVG/PNG и печатный размер IEEE остаются пользователю.
- Пакет синхронный и хранит полный JSON. Время расчёта и объём выгрузки зависят от компьютера; UI не имеет фонового job-прогресса.
- Исследование B включает изменения общей массы исходных весов, без нормализации. Его абсолютные оценки не являются единой измеренной шкалой сложности.
- Корреляции описательные; нет экспертной верификации, эмпирической проверки рекомендаций или доверительных интервалов, основанных на случайной выборке.
- При равных влияниях места рёбер разрешаются лексикографически и не означают научно значимого различия.
