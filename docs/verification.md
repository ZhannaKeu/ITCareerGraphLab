## Покрытые случаи исследовательского ядра

M1 и M2 отдельно; M3 с λ=0; отсутствие дефицита; известные пререквизиты; неизвестные исходные/целевые уровни; пропущенные веса; общий предок ромбовидного DAG; пересечение прямого дефицита с prerequisite-нагрузкой; цепь длиной 2000; циклы/самопетли/несуществующие узлы; детерминированность и валидность Kahn/DFS на 20 DAG с фиксированным seed; порядок входных строк не меняет оценки.

Импорт: повторяемость без дубликатов, сохранение всех исходных строк, MAX-агрегация алиасов, отдельно выбранные источники весов, отказ на дубликатах/NaN/неизвестных группах и маппингах/отсутствующих файлах/расхождении счётчиков. PostgreSQL-тесты проверяют реальное расширение vector и отказ внешнего ключа на несуществующей вершине.

## Сохранённый базовый запуск

- Dataset: `931ef23ff96179ef8aa9567604b6f13b292cb616b40f6131d726873ddfb30751`
- Run: `87fd2cae01a7555e685799dddfc006bead15e979e9bf762d1110e50dad6c1b1b`
- Веса: `skill_weights_by_role_final_v2.csv`, MAX по canonical skill.
- p=1, λ=0.5, Kahn, исходный граф без исключений/добавлений.
- Пример backend:junior → fullstack:middle: M1=14; M2=M3=4.872313261885517. Равенство для этой пары означает отсутствие дополнительной нагрузки при p=1, а не отсутствие пререквизитов в графе.
- Во всём batch дополнительная нагрузка положительна в 78/182 переходах при **данном протоколе**, включая MAX-агрегацию и unit fallback. Это вычислительный результат, не валидация карьерных рекомендаций.
- Полный JSON: `reports/baseline-comparison.json`; CSV: `reports/baseline-transitions.csv`.

В тестах FastAPI/Starlette выдаёт одно предупреждение о будущей замене httpx в TestClient. Проверки проходят; это не ошибка приложения.

После обнаружения и исправления нестабильных default array props React Flow добавлены регрессионные тесты. По просьбе пользователя дальнейшая проверка проводилась **без доступа к экрану**. Финальная визуальная проверка графов в реальном браузере после исправления не выполнялась; jsdom-тесты проверяют runtime и взаимодействия, но не геометрию/пиксели и реальные жесты масштабирования.

GitHub Actions workflow подготовлен и повторяет проверки, но удалённый запуск GitHub Actions не выполнялся: репозиторий не публиковался.

## Повторить

```bash
docker compose up -d --build
docker compose run --rm --no-deps -v "$PWD/datasets:/datasets:ro" -e RUN_POSTGRES_TESTS=1 backend pytest -q -p no:cacheprovider
docker compose exec backend alembic check
npm ci --prefix frontend
npm test --prefix frontend
npm run build --prefix frontend
python3 scripts/smoke.py
```
