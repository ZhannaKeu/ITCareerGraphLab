Дата: 2026-10-31. Приложение, Docker, серверы FastAPI/Vite и браузер не запускались. Проверки HTTP работающего приложения не выполнялись. Старые API-тесты используют внутрипроцессный TestClient с изолированной SQLite; новый тест endpoint-функций вызывает Python напрямую, без HTTP.

PostgreSQL-интеграционные тесты намеренно пропущены, чтобы не запускать сервисы. Получено одно прежнее предупреждение Starlette TestClient об устаревшей интеграции httpx; это не ошибка теста.

## Что покрыто

- Полный фиксированный расчёт 60 сценариев по 182 направленных пары. Во всех сценариях одинаковая M2, при λ=0 M3=M2, при λ≥0 M3≥M2.
- Контроль точных графов/τ/λ, весов Final v2, Kahn, All, отсутствия интервенций, dataset/configuration hashes и связи каждого сценария с сохранённым batch.
- Воспроизведение и кэшированный replay; независимый расчёт полного протокола в новой SQLite даёт равный payload. Предыдущий batch остаётся побитово идентичен в JSON.
- Все 60 агрегатов / 10 920 оценок / 21 840 целевых рангов в CSV, полный JSON с 60 сценариями, параметры, версии и хеши.
- Существующие тесты связей, DAG, моделей, tie-aware Spearman/Kendall τ-b и неопределённых коэффициентов проходят.
- jsdom: реальные SVG-маркеры для одного значения (включая 0), сообщение при пустых данных, отказ пустого экспорта, несколько серий, длинные подписи, XML без parsererror и сохранённое provenance.
- Неполная сетка не превращается в нули; совпадающие числовые/строковые координаты нормализуются; дубли считаются неоднозначными.
- Архивные распределения с разными интервалами безопасно приводятся к общим интервалам по сохранённым значениям. Недостаточные данные дают пустой набор для сообщения, не вымышленные частоты.
- PNG: проверка CRC32 контрольным вектором, корректные новые chunk CRC, UTF-8 iTXt, pHYs 300 dpi. Фактическое рисование Canvas не выполняется в jsdom.
- Новый раздел загружает сохранённый запуск, показывает 60 строк, 7 SVG-фигур, реальные значения тестового payload при переключении τ и четыре точных имени экспорта. Запрос расчёта передаёт только выбранную версию; общий UI других экспериментов его не изменяет.
- Прежние страницы, алгоритмы графа, версии, provenance и старые исследовательские запуски покрыты регрессиями.

## Ограничения

Отображение в настоящем браузере, загрузка файлов через браузер, PNG Canvas и печатная компоновка IEEE не проверялись, согласно ограничению пользователя. Настоящие PostgreSQL/pgvector, миграции и контейнеры в этой итерации не запускались. Внешняя экспертная верификация исследовательских данных не проводилась.

Противоречий в проверенных инвариантах M1/M2/M3 не обнаружено. Формулы и исходные CSV не менялись. Причины пустых графиков описаны как выявленные риски кода, без утверждения о воспроизведении конкретного прежнего браузерного сбоя.
