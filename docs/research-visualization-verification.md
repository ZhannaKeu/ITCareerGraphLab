## Покрытие новых функций

- Локальные подграфы с ограничением глубины и направленные пути без обращения стрелок.
- Детерминированная упаковка компонентов без пересечений карточек на тестовом DAG; сохранность исходных графовых объектов.
- Top-K по выбранной модели и лексикографические tie-breaks; цветовая функция без деления на ноль.
- Проекция экспериментальных включений/исключений без изменения версии графа.
- Экспорт SVG графа и SVG графика/heatmap, корректное XML-экранирование, сохранение метаданных и векторной легенды.
- Средние ранги при равных значениях; неопределённый Spearman на постоянных рангах.
- Сохранение численности распределения M3−M2, отдельная нулевая группа, последний интервал включает максимум.
- Валидация τ/λ: NaN/Inf, диапазоны, дубликаты, лимит 25 комбинаций и Top-K.
- Сохранение/повторное получение research run и batch каждого сценария; отсутствие изменения исходного batch после аналитики.
- При λ=0 M3=M2; при варьировании τ/λ средний M2 остаётся неизменным.
- UI запускает API с выбранной версией и алгоритмом, показывает результаты и экспортные элементы; directed heatmap отличает отсутствие значения/диагональ от нуля.
- Все ранее существовавшие тесты версий, верификации, PostgreSQL FK, импорта и моделей проходят.

## Ограничения проверки

Браузерная проверка не выполнена после явного выбора пользователя завершить без доступа Computer Use. Поэтому реальные жесты, читаемость на конкретном экране, нативное скачивание и PNG-растеризация в Safari не проверены. DOM/unit-тесты и успешная сборка не заменяют визуальный QA. SVG-структура, подписи, легенды и метаданные проверены автоматически. GitHub Actions обновлён существующими командами тестов, но удалённый запуск не выполнялся.

В backend-тестах сохраняется одно предупреждение Starlette о будущем изменении TestClient/httpx; ошибок тестов нет.

## Повторить

```bash
docker compose up -d --build
docker compose run --rm --no-deps -v "$PWD/datasets:/datasets:ro" -e RUN_POSTGRES_TESTS=1 backend pytest -q -p no:cacheprovider
docker compose exec backend alembic check
npm test --prefix frontend
npm run build --prefix frontend
python3 scripts/smoke.py
```

Проверка исследовательского API дополнительно выполнялась POST-запросом из примера в `docs/research-results.md` и проверкой GET `/api/runs/{run_id}` для базового и всех девяти сценарных запусков.
