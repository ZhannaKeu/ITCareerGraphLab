## Новые проверки

- Provenance есть у каждого канонического объекта и исходной строки, включая ссылку на исходный файл/строки. Декларация владельца сохраняется отдельно от статуса.
- Повторный импорт инициализирует сведения о происхождении без изменения исходных ID и CSV.
- Исправления и статусные проверки создают новый снимок; значения и статусы родителя, исходные строки и active pointer остаются прежними.
- Новая версия содержит parent/root, хеш содержимого и статусов; одинаковая правка идемпотентна.
- История содержит автора, причину, время, значения и provenance до/после. Удалённая в новой версии запись остаётся в родителе и истории.
- Подтверждение Source/Expert требует непустых имени рецензента и основания; подтверждение одной записи не распространяется на другие.
- Изменение значения сбрасывает предыдущую проверку; никакое число тестов или пересчитанный счётчик не присваивает Verified.
- Циклы, самопетли, неизвестные узлы/профили/группы, недопустимые уровни и операции блокируют запись новой версии. Зависимые счётчики пересчитываются для исправленного графа.
- Verified scope фильтрует требования, рёбра и выбранные веса; отсутствие покрытия не превращается в нулевой дефицит.
- Исходные и скорректированные версии сравниваются по одним параметрам и всем 182 упорядоченным парам; результат содержит оба provenance и подписанные разности оценок.
- Параметры включают разрешённый version_id. Pair и batch имеют разные run ID; сохранённый JSON возвращается точно по ID. Режим all и verified также различаются в хеше.
- Frontend-тесты проверяют форму новой версии с автором/причиной/рецензентом/основанием и фильтр статусов; сравнение одной версии с самой собой отключено.
- PostgreSQL-тест проверяет создание исправленного снимка со всеми составными FK и сохранение отличающегося запуска. Внешняя транзакция откатывает тестовые данные после внутренних commit сервиса.

## Ограничения проверки

Это проверки программной корректности и воспроизводимости, не экспертная/источниковая верификация научных предпосылок. Реальные внешние документы, Colab notebook и квалификации рецензентов системой не проверялись. UI проверен в изолированном DOM; финальная визуальная проверка в браузере не выполнялась по просьбе пользователя. GitHub Actions подготовлен, удалённый запуск не выполнялся.

FastAPI/Starlette выводит одно предупреждение о будущей замене httpx в TestClient; тесты проходят.

## Повторить

```bash
docker compose up -d --build
docker compose run --rm --no-deps -v "$PWD/datasets:/datasets:ro" -e RUN_POSTGRES_TESTS=1 backend pytest -q -p no:cacheprovider
docker compose exec backend alembic check
npm test --prefix frontend
npm run build --prefix frontend
python3 scripts/smoke.py
```
