# Baseline artifacts

Generated by `python3 scripts/smoke.py --save reports` against the real PostgreSQL-backed API. The JSON records one pair and full provenance; the CSV records every directed pair for the same dataset and fixed parameters. These are software/research computation outputs, not observed career outcomes. See `docs/methodology.md` for formulas, exclusions, fallback assumptions and interpretive limits. Regenerating with `--save` updates only these generated reports, never input CSVs or prior database versions.


The top-level baseline artifacts are historical outputs of implementation 1.0.0, generated **before** the owner clarified the AI-assisted origin of most inputs. They must not be described as validated real-world evidence. They are retained unchanged. Implementation 1.1.0 persists provenance-aware pair and batch runs with distinct IDs; use the application or a new output directory to export a current run, without overwriting the archived baseline.
