# Research Results baseline

`run.json` was computed by the PostgreSQL-backed API for the selected original dataset with mostly AI-assisted Unverified records. It preserves the baseline batch, 182 model comparisons, 9 sensitivity-scenario references, ranking analysis, distribution, parameters, original-byte and canonical-status hashes, model implementation and analysis runtime. It is not empirical evidence of transition difficulty or recommendation efficacy. Existing earlier baseline artifacts were retained unchanged.
